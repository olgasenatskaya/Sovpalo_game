# Совпало! — онлайн-игра на ассоциации

Рабочий прототип: комнаты по коду, WebSocket-синхронизация, роли ведущего и игроков, скрытые ответы, подсчёт очков, смена ведущего, переподключение по сохранённому ID.

## Запуск

```bash
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000`. Для игры на разных телефонах разместите проект на сервере с HTTPS/WSS (например, Render или Railway) и отправьте участникам ссылку. Локальный адрес `localhost` с других телефонов не работает.

## Ограничения прототипа

Комнаты хранятся в памяти и исчезают при перезапуске сервера; нет защиты от спама, ограничения числа комнат, постоянного хранилища или системы администрирования. Для публичного запуска нужны Redis/БД, уборка неактивных комнат и проверка безопасности. Участники, покинувшие игру в середине раунда, могут задержать вскрытие до возвращения.
